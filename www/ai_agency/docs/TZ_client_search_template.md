## 5. Требования к карточке клиента

Для каждого найденного клиента агент должен заполнить:

| Поле | Обязательно | Комментарий |
|------|-------------|-------------|
| `company_name` | да | из title Google |
| `website` | да | URL из выдачи |
| `snippet` | да | сниппет Google |
| `niche` | да | отрасль |
| `pain_hypothesis` | да | 1–3 гипотезы на основе сниппета + цели |
| `usp.headline` | да | 1 предложение |
| `usp.value_proposition` | да | персонально под клиента |
| `usp.differentiators` | да | 2–5 пунктов |
| `usp.call_to_action` | да | следующий шаг |
| `source` | да | всегда `google` |
| `source_query` | да | запрос, по которому найден |

**Запрещено:** выдумывать телефоны, email, Telegram без открытого URL.

---

## 6. Критерии качества УТП

УТП считается хорошим, если:
1. Привязано к конкретной гипотезе боли из сниппета / ниши.
2. Не шаблон «внедрим CRM всем».
3. Есть измеримый/понятный следующий шаг (демо, аудит, созвон).
4. Отличается от оффера конкурентов минимум 2 пунктами.

## 8. Handoff для sales

После поиска `client_hunter` должен передать:
- `recommended_approach` — тон и формат первого касания

## 9. Пример заполненного ТЗ (образец)

```text
Цель: найти 7 компаний e-commerce / селлеров WB-Ozon в РФ,
которым нужна автоматизация сбора заявок из мессенджеров в CRM.

ICP: селлеры/ИМ с оборотом от среднего; ЛПР — собственник или операционный.
Анти-ICP: чистые инфобизы без товарного потока.

Услуга: внедрение n8n/Albato + CRM (Bpium/Amo/Bitrix) под заявки.
Боли: потеря обращений, ручной перенос в Excel, нет единой воронки.

Google-запросы:
1. селлер wildberries автоматизация заявок
2. интернет-магазин интеграция telegram crm
3. ozon продавец обработка заказов crm
4. e-commerce n8n OR albato интеграция

Выход: 5–7 клиентов с УТП; shortlist топ-3 для sales.
```
